# Graph Table 📈📊

Welcome to **Graph Table**, an interactive data visualization project that combines a **graph using D3.js** with a data table for better insights and data representation. This project is designed to display dynamic visual data alongside a table for a comprehensive view of the information.

## About Graph Table

**Graph Table** is a frontend project built using **React**, **D3.js**, and **SASS**. It features:
- A **dynamic graph** built using **D3.js** for visual data representation.
- A **data table** that synchronizes with the graph to display the raw data behind the visualization.

### Features

- **Interactive Graph**: A dynamic graph created using **D3.js**, allowing users to visually interpret the data.
- **Data Table**: A table that shows the raw data corresponding to the values represented in the graph.
- **Synchronization**: The table and graph are linked, meaning changes in one will reflect in the other.
- **Responsive Design**: The project is fully responsive, ensuring a seamless experience on all devices.
- **Data Exploration**: Users can interact with the data to better understand trends and patterns.

### Built With

- **React**: A JavaScript library for building the user interface.
- **D3.js**: A powerful JavaScript library for creating data-driven visualizations and graphs.
- **SASS**: A CSS preprocessor used for better organization and maintainability of styles.

## Legal Disclaimer

**Graph Table** is a frontend tool for visualizing and exploring data using graphs and tables. This project does not handle any personal data and is intended for demonstration and educational purposes.
